# 하루조각 요구사항

## 서비스

- 이름: 하루조각
- 한 줄 소개: 사진 한 장으로 남기는 오늘의 조각
- 종류: 사진 피드 SNS (주제: 일상의 기록)

## 게시물 항목

| 항목 | 타입 | 설명 |
| --- | --- | --- |
| id | string | 게시물 고유 id |
| author | string | 작성자 이름 |
| content | string | 본문 글 |
| images | string[] | 사진 주소 목록 (1~5장) |
| created_at | string | 작성 시각 (ISO 8601) |

## 화면

- 피드 화면 하나
- 게시물 카드가 위에서 아래로 쌓임
- 휴대폰 폭(가로 430px 이하) 기준

## 캐러셀 상태

| 상태 | 보여줄 것 |
| --- | --- |
| 사진 1장 | 캐러셀 없이 사진만 보여줌 |
| 사진 여러 장 (2~5장) | swiper 캐러셀. 스와이프로 넘김. 아래에 점(●○○), 오른쪽 위에 장수 배지(예: 1/3) |

## 무한 스크롤 상태

| 상태 | 문구 |
| --- | --- |
| 처음 불러오는 중 | 오늘의 조각을 모으는 중이에요 |
| 더 불러오는 중 | 조각을 더 가져오고 있어요 |
| 더 없음 | 모든 조각을 다 봤어요 |
| 오류 | 조각을 불러오지 못했어요. 다시 시도해 주세요 (다시 시도 버튼 포함) |

## 분위기

따뜻한 아이보리 배경에 테라코타 포인트 색. 종이 일기장처럼 포근하고 차분한 느낌.
